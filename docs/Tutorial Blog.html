Tutorial on Linear Regression

In this tutorial I am going to show you how to do simple linear regression on data and a question of your choosing. You can follow along with a data set of your choosing or use the data set in this tutorial( found here). Linear regression is a very useful tool in data science and statistics. Linear regression allows you to show the effect of one or more predictor variables on a response variable you are interested in.

tutorial body ## 1. Find a Data Set Start with a question you want to answer: My question is: how does age and number of nearby stores affect the price of a house.

Before we start our analysis let’s check a few things.

  • What each row represents.
  • How each variable is measured.
  • Whether values are missing.
  • Whether the observations are relevant to your question.
  • Whether you have permission to use and share the data.

For this example, assume we have a txt file named RealEstate copy.txt with these columns:

| Column | Description |
|—|—|
| age | Age of a house in years |
| price | Price of a house in $10000|
| stores | Number of stores within walking distance |
| metro | Number of trains within walking distance |
| trails. | NUmber of trails within walking distance |

2. Load the Data

We will use pandas to work with the data and statsmodels to fit the regression.

If these packages are not installed, run this command in your terminal:
bash python -m pip install pandas statsmodels

Then import the packages and read the CSV file:

python import pandas as pd import statsmodels.formula.api as smf

data = pd.read_csv(“RealEstate copy.txt”, sep=r”+“)

the sep argument tells the pd.read_csv function what your values are separated by in the data file.

For this relative file path to work, the CSV must be in Python’s current working directory.

Inspect the data before analyzing it:

python print(data.head()) print(data.columns) print(data.dtypes) print(data.isna().sum())

These commands display the first few rows, column names, data types, and number of missing values in each column.

Check that numeric measurements were loaded as numeric columns. Unexpected text, units, or formatting can prevent the model from treating them correctly.

3. Select Your Variables

Choose the outcome you want to explain and the predictor you want to use.

For our question:

  • Response variable: price.
  • Predictor variable: age.

Select these columns:

python model_data = data[[“price”, “age”]].copy()

For this introductory example, remove rows missing either selected variable:

print(“Rows before cleaning:”, len(model_data))

model_data = model_data.dropna()

print(“Rows after cleaning:”, len(model_data)) print(model_data.describe())

Removing incomplete rows is a simple starting point, but it can change which projects your analysis represents. Investigate why values are missing rather than treating deletion as an automatic solution.

Also check for implausible values and confirm that all measurements use consistent units.

4. Build Your Linear Model

A simple linear regression model has this structure:

text duration_days = intercept + slope \'d7 age + error\

The intercept represents the modeled duration when age is zero. The slope represents the modeled change in price associated with one additional year.

The error captures the difference between an observed duration and the model’s underlying relationship.

### Fit the model in Python

Use this formula:

python\ model = smf.ols(\ formula="price ~ age",\ data=model_data\ ).fit()\

The formula reads:

text\ response variable ~ predictor variable\

Here is what the code does:

- smf.ols() sets up an ordinary least squares regression.
- "price ~ age" identifies the response and predictor.
- data=model_data identifies the dataset containing those columns.
- .fit() estimates the model’s coefficients.

The formula interface includes an intercept by default. Ordinary least squares chooses coefficients that minimize the sum of squared residuals'97the squared differences between observed and fitted outcomes.

### View the results

python\ print(model.summary())\ print(model.params)\

The summary includes coefficient estimates, standard errors, confidence intervals, p-values, and R-squared.

For illustration only, suppose the fitted equation were:

text\ predicted price = 30 + 0.002 \'d7 age\

A year old project would then have a predicted duration of:

text\ 30 + 0.002 \'d7 10,000 = 50 days\

These coefficients are hypothetical, not results from an actual dataset.

### Predict a new outcome

Use the fitted model to predict price for a new project:

python\ new_house = pd.DataFrame(\{\ "age": [10000]\ \})\ \ predicted_price = model.predict(new_house)\ \ print(predicted_price)\

The prediction uses the coefficients estimated from your data. Avoid predicting far outside the range of project sizes used to fit the model.

### Add another predictor

To include cstores, select the necessary columns and fit a new model:

python\ multiple_model_data = data[\ ["price", "age", "stores"]\ ].dropna()\ \ multiple_model = smf.ols(\ formula="price ~ age + stores",\ data=multiple_model_data\ ).fit()\ \ print(multiple_model.summary())\

The model now has this structure:

text\ duration_days =\ intercept\ + coefficient_1 \'age\ + coefficient_2 \'stores\ + error\

Each coefficient describes an association with duration while holding the other included predictor constant. ## 5. Check Before Drawing Conclusions

Fitting the model is only part of the analysis. Before interpreting it:

  • Check whether the relationship is reasonably linear.
  • Examine residuals for patterns or changing spread.
  • Investigate unusual or influential observations.
  • Consider whether observations are independent.
  • If prediction is your goal, evaluate accuracy on data not used to fit the model.

Normality of the errors is relevant to conventional small-sample inference, not a requirement for calculating the fitted coefficients.

A high R-squared does not automatically mean the model is appropriate, and an association does not establish causation. For example, larger crews may be assigned to more difficult projects, so a crew-size coefficient should not automatically be interpreted as the effect of hiring additional workers.

The goal is to build a model that answers your question and remains credible when checked against the data.
